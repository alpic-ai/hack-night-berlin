Overview

This page is the working guide for Berlin Hack Night. The goal is to help you arrive prepared, get moving quickly during the event, and keep the weekend judging deadline in view while you build.

The day before

1

Install the local toolchain

Make sure the whole local loop is already working on your machine before you arrive.

  • Install Node.js 22+ and Git.
  • Install the Codex app or Codex CLI.
  • Create a GitHub account.
  • Create an Alpic account.
  • Ask Codex: "what skills do you have? do you know the skybridge skill?" It should list skybridge as an accessible skill.
2

Read the docs

A short pass through the official material will save a lot of event time once the hack night starts.

You can start with the 9-minute intro: watch on YouTube

9-minute intro Watch on YouTube

Explore Skybridge documentation and examples

  • Documentation Skybridge Docs
  • Reference builds Examples with code
  • Inspiration Apps Showcase
3

Join our Discord

Join the Alpic Discord for questions, updates, and support.

At hack night

1

Confirm your local setup

If you skipped the prep, finish the local toolchain first so you do not lose room time on installs.

2

Redeem your Codex credits

  1. Install Codex.
  2. Join our Discord, and ask for a promo code by sending a DM to @_eldodi, @harijoe, or @neil_ac.
  3. Go to chatgpt.com/p/YOURPROMOCODE and accept the credits. You should receive 2500 Codex API credits.
3

Create the starter app

Scaffold the Skybridge app with the Skill installed globally so you start from the right structure.

npm create skybridge@latest my-app
4

Start the dev environment

Run the dev command to open Skybridge DevTools on localhost, then keep that window open while you iterate.

npm run dev

Or ask Codex with the Skybridge Skill:

launch the skybridge dev server and devtools
5

Build with Codex

Use Codex together with the Skybridge Skill to shape your flow, tools, and UI as you go.

6

Deploy when the core loop works

Once the app behaves the way you want locally in Skybridge DevTools, push it to production with Alpic Cloud.

npm run deploy

Or ask Codex with the Skybridge Skill:

please deploy my app to Alpic

Full deploy docs

7

Test inside ChatGPT

Activate the tunnel, connect the app, and verify the full experience in ChatGPT before submission.

Testing in ChatGPT

Before Sunday, May 31

You have until 23:59 on Sunday, May 31 to refine your build before final submission. That gives teams a full weekend to polish the demo before asynchronous judging begins.

When your project is ready, add your submission to the shared sheet so the judges can review it.

Support & help

The Alpic team will be available on the hackathon premises to help with any issue involving Skybridge and Alpic Cloud. We are easy to identify because we wear pink ski goggles. You can also join the Alpic Discord, check the Skybridge Docs, and the Alpic Docs for the platform.

FAQ

Do I need an Alpic credit card setup?

No. Creating an Alpic account for the hack night does not require a credit card.

How do I know the Skybridge Skill is installed?

Ask Codex: "what skills do you have? do you know the skybridge skill?"

When are winners selected?

Winners are selected during an asynchronous judging round after final submissions close on Sunday, May 31 at 23:59.
